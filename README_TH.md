# YOGIRI — THE END (Forge 1.20.1)

โปรเจกต์ Source Code สำหรับ Minecraft 1.20.1 + Forge 47.2.0, Java 17

## ความสามารถในรุ่นต้นแบบ
- เรียก Yogiri ด้วยคำสั่ง `/summon yogiri_the_end:the_end`
- Entity มีพลังชีวิต/เกราะสูงมาก, กันความเสียหายปกติ, ไม่ despawn ตามระยะ
- ลบ Living Entity ที่ไม่ใช่ผู้เล่นในรัศมี 48 บล็อกเป็นระยะ โดยใช้ `discard()` เพื่อข้ามระบบ HP/เกราะ/การต้านทานความเสียหาย
- Pehkui เป็น optional: ตรวจ API ด้วย reflection; ถ้าไม่ติดตั้งหรือ API ไม่ตรง จะไม่ทำให้เกม crash
- ใช้โมเดล Enderman เป็น placeholder พร้อม texture เฉพาะของม็อด

## ข้อจำกัดที่ต้องทราบ
- รุ่นนี้ **ไม่ลบผู้เล่น** และไม่สามารถรับประกันว่าจะต้าน `/kill`, คำสั่งแอดมิน, ปลั๊กอิน/ม็อดที่สั่งลบ Entity, หรือการแก้ไฟล์โลกได้
- `discard()` เป็นการนำ Entity ออกจากโลกโดยตรง จึงอาจไม่เรียก loot/death event ของม็อดเป้าหมายทุกตัว และม็อดบอสบางตัวอาจมีระบบเกิดใหม่/ป้องกันการลบของตัวเอง
- การลบ Entity อาจทำให้ฟาร์ม, เควสต์, ดรอปไอเทม หรือกลไกของม็อดอื่นเสียสมดุล ควรสำรองโลกก่อนทดลอง
- Pehkui API แตกต่างกันได้ตามเวอร์ชัน; ถ้าตรวจไม่พบ API จะคงขนาดปกติแทนการ crash

## วิธี Build เป็นไฟล์ .jar
1. ติดตั้ง JDK 17
2. แตก ZIP
3. เปิด Terminal ในโฟลเดอร์โปรเจกต์
4. รัน `gradle build` (ต้องเชื่อมต่ออินเทอร์เน็ตครั้งแรกเพื่อดาวน์โหลด ForgeGradle/Forge)
5. ไฟล์จะอยู่ที่ `build/libs/YOGIRI-THE-END-1.0.0.jar`
6. นำ `.jar` ไปไว้ในโฟลเดอร์ `mods` ของ Minecraft Forge 1.20.1
